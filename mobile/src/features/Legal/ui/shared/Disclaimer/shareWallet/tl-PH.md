Malapit ka nang lumikha ng link ng wallet o QR code na naglalaman ng sensitibong datos ng wallet.

## ⚠️ Mga Panganib sa Seguridad:

- Sinumang may link na ito ay maaaring ma-access ang iyong wallet
- Ang mga QR code ay maaaring makuha ng litrato
- Ang mga link ay maaaring mai-save sa kasaysayan ng browser
- Ang sensitibong datos (mnemonic/root key) ay nasa plaintext

Sa pagpapatuloy, kinikilala mo ang mga panganib na ito.
