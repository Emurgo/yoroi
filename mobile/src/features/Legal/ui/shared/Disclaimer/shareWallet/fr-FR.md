Vous êtes sur le point de générer un lien de portefeuille ou un code QR contenant des données sensibles du portefeuille.

## ⚠️ Risques de Sécurité:

- Toute personne ayant ce lien peut accéder à votre portefeuille
- Les codes QR peuvent être photographiés
- Les liens peuvent être stockés dans l'historique du navigateur
- Les données sensibles (mnemonic/clé racine) sont en texte brut

En continuant, vous reconnaissez ces risques.
